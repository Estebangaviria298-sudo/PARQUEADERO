
# Sistema de Parqueadero C++ y Python

## Descripcion
Proyecto academico para administrar un parqueadero mediante comunicacion entre un cliente y un servidor en C++ usando sockets TCP.

## Objetivos
- Generar placas de vehiculos.
- Enviar estructuras de datos entre cliente y servidor.
- Registrar la hora y la celda de cada vehiculo.
- Controlar entradas y salidas.
- Administrar 40 celdas.
- Integrar C++ con Python mediante SWIG.
- Visualizar las celdas libres y ocupadas.

## Tecnologias
- C++
- Python
- Sockets TCP
- SWIG
- Git y GitHub
